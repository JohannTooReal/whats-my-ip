# 🌐 Public IP Checker

This website helps you quickly find out your **public IP address**.

Simply open the website, and it will automatically check your public IP and display it on the screen.

## ✨ Features

* 🌐 Shows your public IP address
* ⚡ Automatically checks your IP when the page loads
* 📱 Works on computers, phones, and tablets
* 🎨 Simple and easy-to-use interface
* 🔒 Does not require you to enter any personal information

## 🛡️ Privacy

This website does not ask you to enter personal information, create an account, or provide a password.

To determine your public IP address, the website sends a request to the **ipify API**. Because the request comes from your device, ipify can see the public IP address making that request.

The website itself does not store your IP address or send it to a personal database.

Keep in mind that using any online IP-checking service means the service receiving the request may be able to see your public IP address. Your public IP address is normally visible to websites and online services you connect to.

## 🛠️ How It Works

The website uses the [ipify API](https://api.ipify.org/) to determine the public IP address that is visible to the internet.

Your public IP will then be displayed directly on the webpage.

## 🚀 Usage

Download or clone the project and open `index.html` in your web browser.

That's it! Your public IP address will be displayed automatically.

## ℹ️ Note

This website displays your **public IP address**, not your local/private IP address (such as `192.168.1.1`).
